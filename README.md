# 🚗 Parking Management System

A Python-based parking management application for registering, displaying, and searching vehicle records.

## ✨ Features

-  **Vehicle Registration:** Register vehicles with their name, color, license plate, and entry time.
-  **Vehicle Listing:** Display all registered vehicles.
-  **Vehicle Search:** Find vehicles by license plate.
- ️ **Duplicate Prevention:** Prevent duplicate vehicle registrations.
- ️ **Input Validation:** Handle invalid menu selections.
-  **Case-Insensitive Search:** Search license plates regardless of letter case.

## 📁 Project Structure

```text
Parking_Management_System/
│
├── parking_main.py      # Main program
├── parking_module.py    # Parking functions and data management
└── parking_test.py      # Manual test examples
```

## 🛠️ Technologies

-  Python 3.10+
- Modular Programming
- Functions
- Lists and Dictionaries

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/ReyhanehMahmoudabadi/Parking_Management_System.git
```

**2. Navigate to the project directory**

```bash
cd Parking_Management_System
```

**3. Run the application**

```bash
python parking_main.py
```

## 🧪 Testing

The `parking_test.py` file contains manual test examples for the main parking functions, including vehicle registration, listing, and searching.

## 📝 Notes

- Vehicle records are stored in memory during program execution.
- All records are cleared when the application is closed.
- Each vehicle is identified by its license plate.
